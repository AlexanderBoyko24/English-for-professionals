# English for professionals

Платформа профессионального английского: каталог курсов, интерактивные уроки,
кабинеты студента и преподавателя, сохранение прогресса по каждому упражнению.

Настройка и публикация описаны в [SETUP.md](SETUP.md).
Быстрый запуск: `node tools/dev-server.js` → <http://localhost:5173>

## Страницы

| Файл | Что делает |
|---|---|
| `index.html` | стартовая: поиск курса, плитки курсов с раскрывающимися направлениями |
| `auth.html` | регистрация (почта, пароль, роль) и вход, в том числе через Google |
| `student.html` | кабинет студента: ФИО, прогресс по курсам, направлениям и темам |
| `teacher.html` | кабинет преподавателя: поиск студентов, группы, прогресс группы |
| `medical/anatomy/index.html` | страница направления: поиск темы и плитки тем с прогрессом |
| `medical/anatomy/1..35.html` | страницы тем |

## Структура

```
assets/
  config.js     ключи Supabase (пусто = локальный режим)
  api.js        слой данных: облачный и локальный режимы за общим интерфейсом
  catalog.js    структура курс → направление → тема
  ui.js         тема день/ночь, шапка профиля, защита страниц
  engine.js     движок урока: упражнения и подсчёт прогресса
  app.css       переменные тем и общие элементы интерфейса
  lesson.css    стили упражнений
data/<курс>/<направление>/<номер>.js   данные уроков
supabase/schema.sql                    таблицы, триггеры и права доступа
tools/dev-server.js                    локальный сервер для просмотра
```

Страницы тем — тонкие обёртки: они подключают общий движок и файл с данными
своего урока. Правка логики упражнения делается в одном месте, а не в 35.
